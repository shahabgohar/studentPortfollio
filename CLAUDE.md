# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Marketing site for Shahab Gohar (AI automation + CRM engineering), built with Nuxt 3 (Vue 3) and Tailwind CSS, statically generated and deployed on Netlify from `master`.

## Commands

```bash
npm run dev        # Dev server on port 3000 (see note below)
npm run build      # Production build
npm run preview    # Preview production build
npm run generate   # Static site generation (what Netlify runs)
node scripts/build-icons.mjs   # Regenerate utils/icons.ts after adding an icon
```

Dev note: on this machine the dev server binds to either IPv4 or IPv6 from run to run, and the other address answers `426 Upgrade Required`. If `http://localhost:3000` gives 426 use `http://127.0.0.1:3000`, and vice versa.

## Design system: "paper, ink, safety orange"

An engineering-datasheet look, chosen to get away from the generic dark developer portfolio. Be realistic about it: this is the recognisable industrial/neo-brutalist genre (it closely matches the `industrial-brutalist-ui` skill's recipe), not a one-off. What is actually specific to this business is the content: the dry-run write-gate demo, the spec table, the 14-day ruler. Protect those. The look: cool aluminium-grey paper, black ink, one safety-orange signal colour, hairline rules, squared corners, and giant condensed poster headlines. The hazard-tape stripe is the brand motif (it stands for the dry-run write gate).

- **Tokens** live as CSS variables in `assets/css/tailwind.css` (`--c-ink`, `--c-paper`, `--c-raised`, `--c-well`, `--c-signal`, `--c-hot`, `--c-on-hot`, `--c-go`). `tailwind.config.ts` maps them to colours. The legacy names every page is written against still work: `primary` = ink, `secondary` = paper, `info` = signal.
  - `info`/`signal` is a burnt orange tuned to pass WCAG AA as small text. `hot` is the pure safety orange for fills; text on it must use `--c-on-hot` (it does not flip in dark mode).
  - Small text needs `text-primary/60` or stronger to pass AA on paper. Do not go lower.
- **Themes:** light is the brand default for everyone (it does not follow the OS). Dark is opt-in via the header toggle, stored in `localStorage['shahab-theme']`, applied before first paint by the inline boot script in `nuxt.config.ts`, and adopted by `composeables/useTheme.ts`. Theme-dependent markup must be CSS-only (`.only-light` / `.only-dark`) so prerendered HTML is identical in both themes.
- **Type:** one self-hosted variable font, Archivo (`public/fonts/archivo-var.v1.woff2`, weight 400–900, width 62–125), plus Martian Mono for data. Width is set with `font-stretch` (utilities `wd-62` … `wd-125`).
  - `.display` = extra-condensed black caps (poster headlines). `.label` = expanded micro caps. `.mono` = data/annotations. `.stamp` = ink on an orange block. `.hazard` = tape stripes. `.btn` + `.btn-hot` / `.btn-ink` / `.btn-line`.
  - Legacy `font-grotesk` renders condensed, `font-ibmMono` renders Martian Mono, so older pages inherit the voice.
  - Fonts are subset (Latin + arrows) with `pyftsubset`. `/fonts/*` is cached immutable (see `netlify.toml`), so **bump the `.v1` suffix** whenever a font file changes.
- **Corners:** the Tailwind radius scale is compressed (`rounded-2xl` = 4px) so legacy classes land on the same sharp language.

## Architecture

- **Layout:** `app.vue` renders `SiteHeader`, the page, `SiteFooter`, and `CookieConsent` globally. Pages must not add their own header/footer/nav.
- **Icons:** `components/Icon.vue` inlines SVG paths from `utils/icons.ts` (Phosphor, generated by `scripts/build-icons.mjs`). Same `name`/`size` API as the old nuxt-icon; legacy `mdi:`/`ic:` names are aliased. Nothing is fetched from an icon API at runtime.
- **Motion:** no animation library. Reveals use CSS scroll-driven animations (`.reveal`) behind `@supports` and `prefers-reduced-motion`, so content is never hidden when unsupported. Never gate above-the-fold content (the H1 is the LCP element) behind an entrance animation or JavaScript.
- **Inner pages are a re-skin, not a redesign.** Projects, blog, services and legal pages kept their old structure (rounded bordered cards, pill badges, mono eyebrows); they only inherited the new colours, fonts and corner radius through the tokens.
- **Copy rule:** `specs`, the demo scenarios and the calculator must only restate what the owner's copy already says. No new numbers, no first-person verdicts, no sample data that resembles a real client or implies a price.
- **Homepage pieces:** `DryRunDemo.vue` (interactive write-gate demo, prerendered parked at the gate), `RoiCalculator.vue`, `DemoVideo.vue` (poster + MP4 fetched only near the viewport), `SectionHead.vue` (3/9 marginal-label grid shared by every section).
- **Composables** live in `composeables/` (intentionally misspelled, so they are NOT auto-imported; import them explicitly): `useMetaTags`, `useJsonLd`, `useServiceSeo`, `useTheme`.
- **SEO rules that bit us before:** never pass the string `'NuxtLink'` to `<component :is>` (it prerenders as a dead element with no href; use `resolveComponent('NuxtLink')`). Keep internal links as real `<a href>` in body content.
- **Do not enable `experimental.viewTransition`.** Most routes are prerendered under both `/path` and `/path/`, so the client router replaces the path on load; Nuxt counts that as a page change and starts a transition that never completes (measured: 4 s of frozen rendering on every service page load). See the comment in `nuxt.config.ts`.
- **Performance, stated honestly:** the homepage's FIRST LOAD is about 200 KB because the two product MP4s wait until they are scrolled near. A visitor who scrolls the whole page still downloads roughly what the old design did (~1 MB); non-video weight went 286 KB → 204 KB. Local Lighthouse (mobile, static build, 3-run median, homepage only) was 97 vs 92 for the old design under identical conditions, but the old design scores 98 on the live Netlify site, so treat the local numbers as relative, not absolute. Re-measure on a Netlify deploy before quoting any figure. Payload extraction is off (no data fetching); fonts are two files.
